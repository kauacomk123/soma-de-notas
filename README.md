# Programa de Cálculo de Média Escolar
Este é um programa em Java que calcula a média de três notas de um aluno e informa se o aluno foi aprovado, em recuperação ou reprovado com base na média.

### Funcionalidade
O programa solicita o nome do aluno e três notas.

Calcula a média das três notas.

Com base na média:

Aprovado: Se a média for 7 ou mais.

Recuperação: Se a média estiver entre 4 e 6,9.

Reprovado: Se a média for abaixo de 4.
